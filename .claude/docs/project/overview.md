# Project Overview

## Purpose
A comprehensive multi-agent system using Claude AI to handle various aspects of software development through specialized agents.

## Key Features
- Multi-agent coordination
- Specialized domain expertise per agent
- Comprehensive logging and tracking
- Context preservation across sessions
- Automated workflow management

## Agents
1. **Main Agent** - Central coordination
2. **Task Agent** - Planning and task breakdown
3. **Fix Agent** - Debugging and fixes
4. **Coder Agent** - Implementation
5. **UI/UX Agent** - Frontend development
6. **Tester Agent** - Testing and QA
7. **Deployer Agent** - Deployment
8. **Documenter Agent** - Documentation
9. **Reviewer Agent** - Code review
10. **Web Search Agent** - Research

## Skills System
24+ specialized skills covering:
- Development (Next.js, TypeScript, etc.)
- Architecture and design patterns
- Testing and deployment
- Documentation and code quality
- Context and workflow management

## Hooks System
20+ event hooks for:
- Task lifecycle management
- Error handling
- Agent transitions
- Deployment tracking
- User interaction logging
