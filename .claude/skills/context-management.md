# Context Management

## Overview
Efficient context management for maintaining awareness across agents and sessions.

## Key Principles
- Track conversation history and decisions
- Maintain context across agent switches
- Preserve important information between sessions
- Efficiently manage context window usage

## Strategies

### Context Preservation
- Store critical decisions in context files
- Maintain conversation summaries
- Track key architectural decisions
- Preserve user preferences and patterns

### Context Switching
- Smoothly transition between agents
- Pass relevant context to new agents
- Avoid context loss during switches
- Maintain conversation continuity

### Context Optimization
- Prioritize relevant information
- Compress historical context
- Remove outdated information
- Keep context focused and actionable

## Best Practices
- Regularly update agent context files
- Summarize long conversations
- Tag important information
- Use structured context formats
- Maintain context relevance
