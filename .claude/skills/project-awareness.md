# Project Awareness

## Overview
Maintain comprehensive awareness of the project structure, status, and history.

## Key Areas

### Project Structure
- Understand directory organization
- Know key files and their purposes
- Track dependencies and relationships
- Monitor configuration files

### Project Status
- Track current development stage
- Monitor active features
- Understand blockers and challenges
- Know what's complete vs in-progress

### Project History
- Track major decisions and changes
- Understand evolution of architecture
- Learn from past issues and solutions
- Maintain changelog awareness

## Awareness Strategies

### Initial Assessment
- Review project documentation
- Analyze directory structure
- Check configuration files
- Read README and setup guides

### Continuous Monitoring
- Track file changes
- Monitor git history
- Review commit messages
- Stay updated on architecture changes

### Knowledge Sharing
- Document discoveries
- Update project documentation
- Share insights across agents
- Maintain project overview

## Best Practices
- Regularly review project status
- Update architecture documentation
- Track dependencies
- Monitor for technical debt
- Document patterns and conventions
