# Memory Retrieval

## Overview
Efficient retrieval and use of historical information, decisions, and context.

## Memory Types

### Short-term Memory
- Current session context
- Recent decisions
- Active tasks
- Immediate history

### Long-term Memory
- Project architecture
- Past solutions
- User preferences
- Historical patterns

### Procedural Memory
- Learned workflows
- Best practices
- Common patterns
- Proven solutions

## Retrieval Strategies

### Context Files
- Agent context.json files
- Project documentation
- User preference files
- Issue history

### Search Techniques
- Keyword search in logs
- Pattern matching
- Temporal queries
- Category filtering

### Indexing
- Tag important information
- Categorize by type
- Index by date
- Link related items

## Best Practices
- Store information systematically
- Use consistent formats
- Tag for easy retrieval
- Maintain relevant information
- Archive outdated data
- Cross-reference related items
- Update when context changes
- Verify retrieved information
